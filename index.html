The pausing discipline is what makes the free tier affordable — an idle project releases its compute and keeps its data.

Why the free tier is affordable, and where that figure comes from

The pack charges only the free projects that are awake in a given month — 45 % still active at year-end, averaged at a 0.6 factor, so 27 % of a year's free projects are billed in any month. v0.5.6's investor sentence quoted “$1.1M, the largest unpaid line”; the workbook computes USD 320,098 before D62 and USD 265,708 after. Any material using the old sentence is quoting a number the model does not produce — that is open item 64, and it is why this page quotes the workbook.

Stated plainly, before anyone asks

Only the Pro price has been surveyed. In FY5, Pro is 19 % of platform revenue, and it is 71 % of the blended ARPU that holds payback at 3–5 months.

So 81 % of the FY5 margin and 71 % of the ARPU are unpriced assumptions. One beta benchmark settles both, and it has to measure Business/Team attach — not sign-ups per EGP.

What is proven, by running it — with the run IDs.

Every claim below is an assertion that fails a CI run, not a design note. Where something is not yet measured, it says so on the same line.

Six questions, answered on real hardware

  • ✓Hibernation releases compute — no pods remain, measured in seconds, not asserted from a spec
  • ✓Wake ends on a working database — first successful SELECT 1 through the Service, not “pod Running”: 12.43 s against a 60 s gate (the spike measured 13.25 s independently)
  • ✓External Postgres operator drives a cluster in its own namespace — the arrangement the platform needs
  • ✓Footprint measured: 57 MiB Postgres idle, empty database — the other 76 MiB of the composition are estimates and are labelled as such
  • ✓Machine printed with every number — 2 cpus, x86_64, because a timing without its machine is not reusable

Tenant storage: five proofs, on a cluster

  • ✓A tenant writes to and reads back its own bucket
  • ✓Another tenant is denied — and the denial is meaningful, because the allowance held first. A “denied” that appears when everything is denied is not isolation, and the test now fails if it sees that
  • ✓The credential secret carries the field names the file service actually reads
  • ✓The bucket records an owner — an ownerless bucket is open to any caller
  • ✓Deleting a project leaves no identity, credentials, policy or binding

Pause and wake: six assertions

  • ✓Waking a project that was never paused is harmless — not a one-way door
  • ✓After a pause: no pods remain (34.46 s) and the state reads dormant
  • ✓Pausing is not deleting — the cluster, credentials and objects all survive
  • ✓The wake ends on a working database inside the gate, and the marker row survives the round trip — the assertion that separates “compute released” from “data lost”
  • ✓Components return after the database answers, so nothing dials a dead Service

And the part most decks leave out

Defects found by running it, not by reviewing it

Nine defects in the design document and five harness bugs were found by executing the build — six manifest defects, one lifecycle omission, one missing object, and four assumptions about how a command reaches a pod. None of them was in the copied upstream code.

Each one now has a check that fails in seconds without a cluster: schema validation with enums, an unbound-variable check, a documented-order check, heredoc manifests parsed, and a denial guard that refuses to read as isolation when nothing works.
